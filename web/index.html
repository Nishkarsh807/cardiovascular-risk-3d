Target Leakage Prevention Protocol
  • Zero Contamination: Input matrix $X$ only contains pre-catheterization clinical examination, demographic, ECG, echocardiographic, and laboratory features.
  • Catheterization Exclusion: Cath (angiographic gold standard) and specific vessel stenosis labels (LAD, LCX, RCA) are exclusively prediction targets, never input features.
  • Clinical Interpretability: SHAP (SHapley Additive exPlanations) values provide local feature attribution for every individual inference.
